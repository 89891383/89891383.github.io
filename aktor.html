OK.ru nie wysyła nagłówków CORS, więc przeglądarka nie odczyta HTML-a bezpośrednio. Wpisz własny proxy (np. Cloudflare Worker) albo zostaw puste — wtedy działa wykrywanie po API Kick.
export default {
  async fetch(request) {
    const target = new URL(request.url).searchParams.get("url");
    if (!target) return new Response("brak ?url=", { status: 400 });
    const res = await fetch(target, { headers: { "user-agent": "Mozilla/5.0" } });
    return new Response(await res.text(), {
      headers: {
        "content-type": "text/html; charset=utf-8",
        "access-control-allow-origin": "*",
        "cache-control": "max-age=5"
      }
    });
  }
};

Informacje prawne

1. Czym jest ten serwis

Ta strona jest panelm widza: pokazuje status kanału, czat i osadzone odtwarzacze (iframe) oraz odnośniki do transmisji prowadzonych na zewnętrznych platformach — Kick (kick.com) i OK.ru (ok.ru).

Serwis nie hostuje, nie przechowuje, nie kopiuje i nie re-streamuje żadnych materiałów audiowizualnych. Nie posiada serwera plików ani infrastruktury strumieniowej. Obraz i dźwięk są pobierane bezpośrednio przez Twoją przeglądarkę z serwerów operatorów zewnętrznych, na ich warunkach i w ich odtwarzaczach.

2. Brak powiązań z platformami

Serwis nie jest powiązany z Kick.com, OK.ru, Discordem ani Tipply. Nazwy i znaki towarowe należą do ich właścicieli i są używane wyłącznie w celach informacyjnych (wskazanie źródła).

3. Odpowiedzialność za treść

Za treść transmisji odpowiada wyłącznie jej nadawca oraz operator platformy, na której transmisja jest prowadzona. Serwis nie ma wpływu na to, co pojawia się w osadzonym odtwarzaczu, i nie moderuje treści wideo. Nie odpowiada za przerwy, błędy ani usunięcie materiału przez operatora źródła.

4. Prawa autorskie — zgłoszenia (notice & action)

Jeśli jesteś uprawnionym i uważasz, że osadzony materiał narusza Twoje prawa, wyślij zgłoszenie na adres [email protected] zawierające: dane zgłaszającego, wskazanie utworu, dokładny adres URL podstrony oraz oświadczenie o uprawnieniu. Zgłoszenia rozpatrujemy niezwłocznie — usuwamy odnośnik lub osadzenie. Podstawa: art. 16 rozporządzenia (UE) 2022/2065 (DSA) oraz art. 14–15 ustawy o świadczeniu usług drogą elektroniczną.

Osadzanie cudzych materiałów nie jest neutralne prawnie: zgodnie z orzecznictwem TSUE (m.in. Svensson C-466/12, GS Media C-160/15, VG Bild-Kunst C-392/19) frame może być „publicznym udostępnieniem”, jeśli omija zabezpieczenia techniczne lub działa w celach zarobkowych. Serwis działa niekomercyjnie i nie obchodzi zabezpieczeń — ale zgłoszenia i tak realizujemy.

5. Treści dla dorosłych (18+)

Kanał może oznaczać transmisje jako 18+ (pole is_mature w API Kick). Wejście wymaga potwierdzenia pełnoletności.

Stan prawny na 25.11.2026: w Polsce nie obowiązuje jeszcze odrębna ustawa wprowadzająca obowiązkową weryfikację wieku. Rządowy projekt „ustawy o ochronie małoletnich przed dostępem do treści pornograficznych w internecie” (druk 2697, przyjęty przez Radę Ministrów 2.06.2026, po pierwszym czytaniu w komisjach) przewiduje w art. 4, że mechanizm weryfikacji nie może polegać na samodzielnej deklaracji wieku, oraz wskazuje elektroniczne poświadczenie atrybutu wieku z europejskiego portfela tożsamości cyfrowej (EUDI Wallet) jako mechanizm preferowany. Do tego czasu obowiązują: art. 28 DSA (ochrona małoletnich, środki proporcjonalne) oraz art. 200 § 3 i § 5 oraz art. 202 Kodeksu karnego.

Dlatego brama wieku w tym serwisie ma charakter samooceny i zostanie zastąpiona weryfikacją atrybutu wieku, gdy tylko będzie to technicznie i prawnie wymagane.
